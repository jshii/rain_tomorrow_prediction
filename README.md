Rain Tomorrow Prediction 🌧️
Project Overview
This project uses Machine Learning to predict whether it will rain the next day based on weather conditions.
The goal is to build a classification model that learns from historical weather data and predicts the possibility of rain tomorrow.
Dataset
• Source: Kaggle – USA Rainfall Prediction Dataset 2024–2025 (https://www.kaggle.com/datasets/waqi786/usa-rainfall-prediction-dataset-2024-2025)⁠
• Number of records: 73,100
• Target variable: Rain Tomorrow
 • 0 = No Rain
 • 1 = Rain
Technologies & Libraries
• Python
• Pandas
• NumPy
• Matplotlib
• Scikit-learn
• Google Colab
Project Workflow
1. Data exploration and analysis.
2. Data preprocessing.
3. Splitting data into training and testing sets.
4. Feature scaling using MinMaxScaler.
5. Training a Logistic Regression classification model.
6. Making predictions.
7. Evaluating model performance.
Model Evaluation
The model was evaluated using:
• Accuracy Score
• Confusion Matrix
• Classification Report
• Precision
• Recall
• F1-Score
Model Accuracy: 90.57%
Visualizations
The project includes visualizations to explore the distribution of rainfall and understand the dataset.
